Atividades práticas de Programação Web I (Técnico em Informática).

## Projetos
- 01-hello-world: primeira página em PHP
- 02-data-hora: data e hora do servidor
- 03-imc: calculadora de IMC
- 04-produtos: lista de produtos com array associativo

## Como executar
1. Instalar o Laragon e iniciar os serviços.
2. Colocar esta pasta em C:\laragon\www\php-basico.
3. Abrir http://localhost/php-basico/ no navegador.

## O que aprendi
- O PHP roda no servidor e o navegador recebe só o HTML pronto.
- Variáveis, concatenação e interpolação com aspas duplas.
- Condicionais (if/elseif) para classificar o IMC e escolher a saudação.
- Arrays associativos e foreach para montar tabelas.
- Usar htmlspecialchars() para proteger a saída.
